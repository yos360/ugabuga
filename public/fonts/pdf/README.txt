Noto Sans Hebrew, SIL Open Font License 1.1 (see OFL.txt).
Source: https://github.com/google/fonts/tree/main/ofl/notosanshebrew
Downloaded 2026-10-18. The variable font was instantiated with fontTools 4.67.0
at wght=400, wdth=100. No glyph outlines were redrawn.
metrics.json contains cmap glyph IDs, advance widths, bounding box and ascent/
descent normalized to 1000 units. The font is fetched only when exporting PDF,
and embedded so the invisible searchable text does not depend on system fonts.
Visual worksheet artwork remains the existing raster rendering.
This is not a PDF/UA conformance claim or a substitute for screen-reader testing.
