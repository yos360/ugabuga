2. להחליט אם לפתוח משימת ביצועים נפרדת עבור 230 הדפים שמעל הסף.
3. אם רצויה אחידות בהדפסה, להחליט בנפרד על העברת 33 דפי ההדפסה הישנים לתצוגה החדשה. לא הוסבה מערכת ההדפסה במסגרת הבדיקה.
4. להשלים בדיקה ידנית של ניצחון בשני משחקי הסוליטר, שמיעה/מיקרופון אמיתיים, ותהליכים הזקוקים לשירות החיצוני. בדיקות אלה לא סומנו כעברו.

**מגבלת שירותים חיצוניים:** תעבורה ל־Supabase, Google Analytics/Fonts ו־Wikipedia נחסמה או לא הייתה זמינה. 26 דפי ספקים הציגו הודעת טעינת שירות; אין להסיק מכך שהשירות החי תקול. לא אומתו רשומות ספקים חיות, פעולות חשבון, פרסום מבחנים/הגרלות או כתיבה לשרת. הגופנים החיצוניים עשויים להשפיע על המראה. הבדיקה היא של הבנייה המקומית, לא של פריסה ב־Cloudflare; לא שונו הגדרות הפריסה.

## שחזור הבדיקה

נדרשים Node, Chrome/Chromium והכלים של המאגר. התקנת תלויות הביקורת הזמניות אינה משנה את תלויות האתר:

```sh
npm ci
node scripts/generate-sitemap.mjs
node scripts/generate-routes.mjs
node scripts/generate-llms.mjs
npx vite build
npm install --prefix out/audit/deps --no-save --package-lock=false jsqr pdf-lib pngjs
npx vite preview --port 5199
```

ב־PowerShell מגדירים לפני הרצה: `$env:AUDIT_BASE='http://127.0.0.1:5199'` ו־`$env:CHROME_PATH='C:/Program Files/Google/Chrome/Application/chrome.exe'`. ב־Linux מגדירים משתני סביבה מקבילים עם נתיב Chromium המתאים. `pdf-qr.mjs` דורש גם `pdftoppm` ב־PATH.

כל שורה בטבלה היא פקודת הרצה בפני עצמה. מריצים לפי הסדר, לא את כל השורות במקביל. הסריקה משתמשת בארבע לשוניות; יתר הסקריפטים בדפדפן משתמשים בלשונית אחת כל אחד.

הפלט המלא נשמר ב־`out/audit/`, לרבות תמונות ו־PDF, ואינו נכלל כולו ב־Git. להרצה נקייה יש להשתמש בתיקיית עבודה נקייה או להזיז את פלט הבדיקה הקודם. אפשר להשתמש ב־`AUDIT_LIMIT`/`AUDIT_FILTER` לסריקה קצרה; אין לסמן הרצה מוגבלת כביקורת מלאה. אפשרויות החלוקה של `print.mjs` מיועדות להרצה מבוקרת בלבד; אין לעבור שש לשוניות בסך הכול.

לפני כל תיקון שנמסר: בנייה עברה, oxlint ללא שגיאות, וכל **601 בדיקות הבסיס** עברו. בענף הלמידה עברו **602 בדיקות**, כולל בדיקת רגרסיה לפתרון ייבוא הרכיבים. אזהרות קוד ובנייה קיימות, לרבות אזהרות גודל קבצים, לא הוסתרו ולא תוקנו במסגרת זו.
