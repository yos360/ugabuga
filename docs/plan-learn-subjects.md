# תוכנית: שיעורים לפי מקצוע (/learn/<מקצוע>/<שיעור>)

> **לבעל האתר, בקצרה:** המטרה היא אלפי דפים — אבל כל דף הוא שיעור אמיתי, לא דף דל. מאז 2024 גוגל מעניש אתרים שמייצרים המוני דפים בתבנית ריקה ("scaled content abuse"), והעונש יכול להוריד את כל האתר. לכן גדלים בגלים: כל גל מוסיף שיעורים מלאים, נבדק, ורק אחרי שגוגל מתחיל להציג אותם — ממשיכים.

## מה כבר בנוי (גל 1)
- ארבעה מקצועות: תנ״ך, לשון, אזרחות, מדע וטכנולוגיה — עמוד מקצוע ושיעורים.
- כל שיעור: פתיח שעונה על שאלת החיפוש, 3–5 פרקים (300+ מילים), "חשוב לזכור", חידון של 8 שאלות עם הסברים, דף עבודה להדפסה עם דף תשובות, 3 שאלות לשיחה, 3 שאלות נפוצות (FAQ schema), קישורים לשיעורים קשורים.
- קוד: `src/learn/subjects/` — `subjects.js` (המקצועות), `data/<מקצוע>.js` (השיעורים), `SubjectPages.jsx` (הדפים). בדיקות: `tests/learn-subjects.test.mjs`.

## איך מוסיפים שיעור (לכל סוכן: Claude או Codex)
1. מוסיפים אובייקט לאחד מקובצי המקצוע ב-`src/learn/subjects/data/` (רשימת הקבצים של כל מקצוע: `SUBJECTS[].files` ב-`subjects.js`; התשובה הנכונה תמיד ראשונה ב-`options` — האתר מערבב). מושגים: `data/<מקצוע>-concepts.js`.
2. מריצים `node scripts/generate-learn-subjects.mjs` — הוא מעדכן את מפת האתר, החיפוש, עמודי הכיתה והמבחנים.
3. `node --test tests/*.mjs`, `npx oxlint`, `npx vite build`.
4. **דיוק לפני הכול:** רק עובדות מוסכמות; כשלא בטוחים — משמיטים. בתנ״ך — בלי ציטוטים מהזיכרון, רק הפניה לספר (ולפרק רק כשבטוחים). באזרחות — בלי פוליטיקאים, מפלגות ומחלוקות עכשוויות.
